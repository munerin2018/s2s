サーバーを持たない SNS の最初の公開版です。

Twitter 型のタイムライン、Instagram 型のメディア一覧、2ch 型の掲示板を、
**ひとつの署名付きログ**の上に載せています。3 つのデータモデルではなく、同じログへの 3 つのクエリです。

アカウントサーバーも、データベースも、CDN も、リレーの契約もありません。
あなたのアカウントは鍵そのもので、投稿はあなたの端末の追記専用ログに積まれ、
つながったピアへ直接複製されます。

## ダウンロード

| | |
|---|---|
| **S2S-android.apk** | Android 版。署名なしのデバッグ版なので、インストール時に警告が出ます |
| **s2s-web.zip** | Web 版。完全な静的ファイルで、好きな静的ホスティングに置けます |
| **s2s-peer-windows-x64.exe** | 画面なしの常時起動ピア（Rust 製、単体で動きます） |

PC アプリはソースから `npm install && npm run desktop` で起動してください。

## 最初の接続だけ手動です

PC どうしは**同じ Wi-Fi にいるだけで自動的に見つかります**（mDNS）。

スマホと Web 版はブラウザと同じ制約下にあり自力で発見できないので、
PC アプリの「設定」タブに出ている `/ws/` を含むアドレスを貼り付けてください。
Web 版なら `index.html#peer=/ip4/.../ws/p2p/...` と URL に書いておけば自動でつながります。

## 入っているもの

- 投稿・返信・いいね・リポスト・フォロー・ブロック・通知・プロフィール
- 画像と動画（内容ハッシュで参照し、持っているピアから取得）
- 板とスレッド、レス番号
- 検索（手元に複製されているものだけ）
- 削除（自分のイベントのみ。墓標であって消去ではありません）

## 2 つの実装

`rust/s2s-peer` に、同じプロトコルを話す独立した Rust 実装があります。
データディレクトリの形式も同じなので、片方が書いたものをもう片方が読めます。

両者は互いにではなく [docs/canonical-vectors.json](../docs/canonical-vectors.json) に照らして
検証されます。署名対象のバイト列で食い違うと、その著者のログは実装をまたいで
**恒久的に複製されなくなる**ためです。

## 知っておいてほしいこと

完全 P2P なので、中央サーバーが黙って引き受けていた仕事が返ってきます。

- **オフラインの相手の投稿は見えません。** 常時起動のピアを 1 つ置くとかなり楽になります
- **検索は手元にあるものだけです**
- **画像は誰も持たなくなれば消えます**
- **鍵を失うとアカウントは戻りません。** 設定タブからバックアップを取ってください
- **スパム対策は弱いです。** 今あるのはブロックだけで、鍵は無料で作れます
- **投稿はすべて公開です。** 暗号化も DM もありません

詳しくは [docs/LIMITS.md](../docs/LIMITS.md) に、設計上の割り切りと未実装を分けて書いています。

## セキュリティ

公開前にレビューを通し、悪意あるピアから実際に悪用できた欠陥を修正しました。
パストラバーサル（アカウントの秘密鍵が漏れるもの）、リモートクラッシュ、
リモートハング、他人の投稿の検閲、実装間の分断などです。

回帰テストは `packages/core/test/hostile.test.js` と Rust 側の `mod tests` にあります。
それでもまだ 0.1.0 です。見つけたら [SECURITY.md](../SECURITY.md) の手順で教えてください。
