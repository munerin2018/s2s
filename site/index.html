S2S

サーバーを持たない SNS。
投稿はあなたの端末に署名付きで積まれ、つながった相手へ直接届きます。

維持費ゼロ アカウント登録なし PC / iPhone / Android / Web AGPL-3.0
今すぐ開く ダウンロード GitHub で見る

インストール不要。開いた瞬間にあなたの鍵が作られます。

これは何か

3 つの形の SNS を、ひとつの仕組みの上に載せたものです。

🏠

Twitter 型

タイムライン、返信、いいね、リポスト、フォロー、ブロック、通知。

🖼

Instagram 型

画像・動画つきの投稿だけをグリッドで。実体はハッシュで参照され、持っているピアから直接届きます。

🧵

2ch 型

板とスレッド。レス番号は >>1 から連番。板は誰でも作れて、名前が同じなら同じ板です。

サーバーがない、とは

アカウントサーバーも、データベースも、CDN も、リレーの契約もありません。 あなたのアカウントは 鍵そのもので、投稿はあなたの端末の追記専用ログに署名付きで積まれます。 他のピアはそのログを複製するだけで、誰も「正本」を持ちません。

「誰がサーバー代を払うのか」への答え。
PC 版が入口になります。同じ Wi-Fi なら設定ゼロで互いを見つけ、NAT 越しの端末どうしの中継も引き受けます。 止めれば止まり、他の誰かがオンラインなら網は生き続けます。払う先がありません。

どう動いているか

通信より先に、データの形を決めてあります。

層役割
イベント投稿も返信もフォローも、すべて ed25519 で署名された 1 件のイベント
ログ人ごとの追記専用チェーン。1件でも改竄すると以降すべてが壊れる
ゴシップ今この瞬間の投稿を即座にばらまく
同期オフラインだった間の抜けを埋める。SNS ではこちらが本命
メディア投稿はハッシュだけを持ち、実体は持っているピアから取りに行く

仕様は docs/PROTOCOL.md にあります。 別実装を書くのに足りるだけ書いてあり、実際に JavaScript 版と Rust 版がこの文書だけを根拠に通信しています。

ダウンロード

まず PC 版を入れてください。スマホと Web 版はそこにつなぎます。

💻 PC 版 Windows / macOS / Linux。ソースから npm run desktop で起動します。 🍎 iPhone / iPad Web 版を開いて「ホーム画面に追加」。App Store も Apple の開発者登録も要りません。 🤖 Android APK S2S-android.apk。提供元不明のアプリの許可が必要です。Web 版でも同じことができます。 🌐 Web 版 ここで開けます。完全な静的ファイルなので、自分のホスティングに置くこともできます。 🦀 常時起動ピア Rust 製。数 MB で動くので、ラズパイや余っているマシン向け。
Android の APK は署名なしのデバッグ版です。 Play ストア経由ではないので、インストール時に警告が出ます。 気になる場合はソースから自分でビルドしてください（npm run mobile:build）。

ソースから

# Node.js 20 以上が必要です
git clone https://github.com/munerin2018/s2s.git
cd s2s
npm install

npm run desktop        # PC アプリ
npm run build:web      # Web 版（packages/ui/dist に出ます）
npm run mobile:build   # Android APK（JDK 21+ と Android SDK が必要）
node scripts/peer.js   # 画面なしの常時起動ピア

iPhone で使う

App Store には出せません。その代わり、審査も開発者登録も要りません。

  1. Safari で Web 版を開く

    この Web 版を Safari で開きます（Chrome ではホーム画面追加が正しく動きません）。

  2. 「ホーム画面に追加」

    共有ボタン → 「ホーム画面に追加」。アイコンが並び、次からは全画面のアプリとして開きます。

  3. PC 版の QR をカメラで読む

    PC 版の「設定」タブに QR コードが出ています。iPhone の標準カメラで読むだけで、アプリが開いてそのまま繋がります。アドレスを手で打つ必要はありません。

なぜ App Store ではないのか。 iOS にネイティブアプリを配るには Apple Developer Program が必要で、年 99 ドルかかります。 維持費ゼロという前提とまっすぐ衝突するので、ここでは採っていません。 ホーム画面に追加した Web 版は、見た目も操作も普通のアプリと変わりません。

iPhone だからこその注意点

  • 鍵のバックアップは必ず取ってください。iOS は、しばらく使っていない Web アプリの保存データを自分で消すことがあります。消えるとアカウントは戻りません。設定タブの「秘密鍵を表示する」から控えてください。
  • アプリを閉じている間は同期しません。iOS は Web アプリをバックグラウンドで動かし続けないので、開いている間だけ繋がります。これは Android の Web 版も同じです。
  • 同じ Wi-Fi にいる必要があります。PC 版を自動では見つけられないので、最初の 1 回だけ QR で教えます。
ネイティブの iOS アプリを自分でビルドしたい場合。 Mac と Xcode があれば npx cap add ios で作れます。 手順は docs/IOS.md に書いてあります。 ただし実機に入れるには結局 Apple のアカウントが要ります（無料アカウントなら 7 日で期限切れ）。

使い方

最初の一回だけ、相手を教える必要があります。そのあとは自動です。

  1. PC 版を起動する

    起動した時点であなたの鍵が作られ、それがアカウントになります。登録もメールアドレスもありません。

    「設定」タブに自分のアドレスが並びます。/ws/ を含む行が、スマホと Web 版から接続するためのものです。

  2. 2 台目をつなぐ

    PC どうしなら、同じ Wi-Fi にいるだけで自動的に見つかります。設定は要りません（mDNS）。

    スマホと Web 版はブラウザと同じ制約下にあるので自動発見ができません。ただし PC 版の設定タブに出る QR コードをスマホのカメラで読むだけで済みます。手で貼り付ける必要はありません。

    # Web 版なら URL に書いておけば自動接続します
index.html#peer=/ip4/192.168.0.10/tcp/4002/ws/p2p/12D3Koo...

  3. あとは普通に使う

    投稿すると、つながっている相手に自動で届きます。相手がその先の誰かとつながっていれば、そこへも伝わります。

    フォロー、いいね、返信、板へのスレ立て。どれも「自分のログに 1 件追記する」ことでしかありません。

鍵のバックアップを取ってください

設定タブの「秘密鍵を表示する」から控えられます。 鍵を失うとその人格は二度と取り戻せません。 再発行してくれる主体が存在しないからです。Web 版はブラウザのサイトデータを消すと鍵も消えます。

正直に言っておくこと

中央サーバーが黙って引き受けていた仕事は、全部こちらに返ってきます。

  • オフラインの相手の投稿は見えません。誰かが中継して持っていれば見えます。常時起動のピアを1つ置くとかなり楽になります。
  • 検索は手元にあるものだけです。世界中のピアに問い合わせることはできません。
  • 画像は誰も持たなくなれば消えます。人気のあるものは多くのピアに複製されて残り、誰も見なかったものは消えます。
  • 鍵を失うとアカウントは戻りません。
  • スパム対策は弱いです。今あるのはブロックだけで、鍵はいくらでも作れます。Sybil 攻撃への耐性はありません。
  • 投稿はすべて公開です。暗号化も DM もありません。
  • 削除はお願いでしかありません。受け取っていないピアには効きません。一度出したものは取り消せないと考えてください。

どれが設計上の割り切りで、どれが未実装かは docs/LIMITS.md で分けて書いています。

セキュリティについて。 イベントはすべて署名され、ログはハッシュ連鎖で、メディアは内容ハッシュで名前がついています。 公開前にコードレビューを通し、悪意あるピアを想定したテストを別に用意しました （パストラバーサル、先回りした削除、不正な同期ベクタ、並行書き込みなど）。 それでもまだ 0.1.0 です。見つけたら Issue をください。
