プライバシーポリシー

S2S（アプリ・Web 版・デスクトップ版）　最終更新 2026 年 9 月 25 日

S2S はサーバーを持たないピアツーピア型の SNS です。 開発者は、利用者の個人情報を収集・保存・送信する仕組みを一切持っていません。 このページでは、データがどこにあり、誰に届くのかを具体的に説明します。

1. 開発者が収集する情報

ありません。アカウント登録、メールアドレス、電話番号、位置情報、連絡先、端末識別子、 利用状況の解析、広告 ID、クラッシュレポートのいずれも、開発者は受け取りません。 開発者が運営するサーバーやデータベースは存在しません。

2. あなたの端末に保存される情報

内容説明
アカウントの鍵アプリを初めて開いたときに端末内で作られる暗号鍵です。これがアカウントそのものです。端末の外には送られません。
あなたの投稿と操作投稿・返信・いいね・フォロー・ブロック・プロフィールなど。
受信した他の利用者の投稿つながった相手から複製された公開投稿と画像。
設定接続先、非表示にした投稿、利用規約への同意など。

これらはアプリを削除するか、アプリ内の「アカウントの削除」で消去できます。

3. 他の利用者に送信される情報

あなたが投稿した内容は公開され、他の利用者の端末に直接送信・複製されます。 これはこのアプリの基本的な仕組みです。対象は次のとおりです。

  • 投稿・返信・スレッドの本文と、添付した画像・動画
  • プロフィール（表示名・自己紹介）
  • いいね・リポスト・フォロー・ブロック・削除の操作
  • あなたの公開鍵（アカウント ID）と、各操作の時刻

また、通信の仕組み上、接続した相手にはあなたの IP アドレスが見えます。 これはあらゆる直接通信に共通する性質で、S2S が特別に送っているものではありません。

通信経路は Noise プロトコルで暗号化されています。ただし投稿そのものは公開情報として扱われ、暗号化されずに相手の端末に保存されます。秘密にしたい情報は投稿しないでください。

4. 外部サービスへのアクセス

サーバーを持たない代わりに、無料の静的ホスティングを次の用途でのみ使います。

用途アクセス先送られるもの
管理者の非表示リストの取得（設定で無効化できます）GitHub Pages（GitHub, Inc.）通常の Web ページ閲覧と同じ情報（IP アドレス等）。あなたの投稿や鍵は送られません。
Web 版・紹介ページの配信GitHub Pages同上
通報フォーム（通報時に利用者が開いた場合のみ）GitHub投稿の ID と通報理由。GitHub のプライバシーポリシーが適用されます。

GitHub のプライバシーポリシー：GitHub 一般プライバシーステートメント

5. 広告・解析・トラッキング

ありません。第三者の SDK、広告、解析ツールは組み込んでいません。

6. アプリの権限

  • インターネット：他の利用者の端末と直接通信するために使います。
  • 画像の添付は OS の標準のファイル選択画面を通して行い、写真ライブラリ全体へのアクセス権は求めません。

7. データの削除

アプリ内の「設定 → アカウントの削除」から、端末上の鍵・投稿・画像・設定をすべて消去できます。 消去の前に、自分の投稿すべてに削除を送信することもできます。

すでに他の利用者の端末に複製された投稿を、開発者が消すことはできません（開発者はそれを保持していないためです）。 削除の送信は、それを受け取った端末で投稿を非表示にしますが、オフラインのまま再接続しない端末に残った複製までは消せません。 詳しくはアカウントの削除をご覧ください。

8. 子どもの利用

S2S は 18 歳以上を対象としています。18 歳未満の方は利用できません。

9. 変更

このポリシーを変更する場合は、このページを更新し、上部の日付を改めます。
